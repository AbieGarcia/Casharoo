# Casharoo — Financial Education App

## About the Project
Casharoo is a financial education mobile application designed to help children and teenagersaged 8–18 develop healthy financial habits through interactive and
engaging learning experiences.

The app makes financial concepts easier to understand by combining educational content with interactive activities, allowing young users to learn about money 
management in an accessible and enjoyable way.

## Key Features
- Interactive Stories: Learn financial concepts through engaging stories and real-life scenarios.
- Educational Games: Reinforce financial knowledge through interactive games and activities.
- Savings Goal Tracking: Set personal savings goals and track progress toward achieving them.

## Tecnologies
- TypeScript
- Ionic React
- Firebase
